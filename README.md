Exactly one word — the word grandma would text about AI — for the [One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16) bounty on make.fun.

## The word

> robit

Five letters. Grandma means "robot" and types it the way she hears it: warm, a little baffled, and completely sure of herself. It is the typo she would actually make, it is funny with no caption needed, and it is unmistakably about a machine.

## How it works

`main.py` writes the word to `/output/entry.txt`, deterministically (two runs produce byte-identical output).

```sh
python3 main.py
cat /output/entry.txt
```
